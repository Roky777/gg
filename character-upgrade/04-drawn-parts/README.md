# Newly drawn source artwork — edge treatment review

Preview: http://127.0.0.1:4173/character-upgrade/04-drawn-parts/index.html

Eight newly generated transparent source sheets cover body, arms, two glove sets,
legs/shoes, clean head, eye features and mouths. The image-generation prompts are
preserved in `prompts/`. These are new drawings guided by the original character;
they are not crops from the original low-resolution model.

Built-in image_gen produced the artwork and edge edits. Generated PNGs are copied
into this project with their alpha preserved. Original generations and successive
join revisions remain available, with no destructive replacement of the game atlas.

Latest join candidates:
- `01-body-join-v2.png`
- `02-arms-join-v2.png`
- `04-legs-join-v2.png`

Visible sleeve hems were restored after an overly soft first pass. Do not equate
this with finished rigging: the leg cap haze and neck/waist rims are still too
broad/bright, and some root outlines remain. These candidates are not promoted.
The next correction must precisely mask concealed terminal bands, retain lateral
contours, remove cap rims and verify colour continuity in registered assemblies.
Only then should joint bends and all gesture hand swaps be certified.

No production quality or 95% identity claim is made. No working game character
texture, skeleton or animation was replaced by these sheets. Existing optional
sports-candidate URLs refer to the earlier cutout experiment, not these new sheets.

`edge-review.json` records native dimensions, transparency statistics and visual
limitations. Transparency statistics are diagnostic, not artistic acceptance.
